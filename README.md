# Apékama — Static GitHub-Ready Website

Rebuilt from the supplied project as a frontend-only site.

### Stack
HTML5 · CSS3 · JavaScript · Font Awesome CDN · localStorage

### Removed
PHP, MySQL/database scripts, admin/auth PHP, server-side form handlers, and the Google Maps/location section.

### Working features
- Responsive navigation + mobile menu
- Light/dark mode
- Product search/filter/sort
- Add/remove/update cart
- Persistent cart via localStorage
- Checkout validation + demo order reference
- Reviews saved locally
- Demo account saved locally
- Contact form opens the visitor's email client
- GitHub portfolio links

### Before publishing
Replace `https://github.com/` in the HTML/footer and `js/config.js` with your real GitHub profile/repository URL.

### GitHub Pages
Put these files in the repository root and enable GitHub Pages. `index.html` is the entry point.
